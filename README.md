# fr-monitor

PopDEX × Variational のFR（資金調達率）差を5分ごとに監視して、Telegramに「エントリー / 乗り換え / 撤退 / 証拠金移動」の指令を出すボット。注文は自分で出す。

## 仕組み

- GitHub Actions で5分ごとに `node monitor.js` を実行
- 両取引所の共通銘柄をすべて走査（出来高・スプレッドで絞り込み）する
- FR差は現在値と6時間の平均（指数移動平均）の**低いほう**で見込む。一瞬の跳ねでは判断しない
- 新しく見え始めたペアは60分観測してから判定に使う

### 常時保有モード（初期設定）
ポイントは建玉を長く置いたほうが貯まるので、**常にポジションを持ち、できるだけ長く持つ**前提で動く。

- 空き枠があれば、FR差が小さくても「30日持つ前提でコストを割った見込み」が一番いい1本を指令（見込み −0.005%/日 までは許容）。建てるまで3時間ごとに催促
- 建ててから24時間は乗り換え提案をしない（悪化しているときは別）
- FRの向きが入れ替わったら、同じ銘柄で売り買いを逆にする「反転」も候補に入れる
- 乗り換えは、受取差が 0.02%/日 以上良くなり、コストを3日以内に回収できるときだけ
- 平均の受取差が −0.01%/日 を下回ったまま24時間続いたら、**降りるのではなく一番いい別ペアへの乗り換え**を指令。乗り換え先が無いときだけ撤退

### 厳選モード
`モード 厳選` で切り替え。FR差が 0.02%/日 以上・回収7日以内のときだけエントリーし、平均がマイナスのまま `exitHours` 続いたら撤退。

### 共通
- 毎日21時（日本時間）に日報（その日のFR、通算損益、上位候補）

## 状態の保存

状態（保有・設定・FRの平均・Telegramの既読位置）は **`state` ブランチの `state.json`** に1コミットだけ置き、毎回上書きする。main の履歴は増えない。
main の `state.json` は初回の種としてだけ使う。

## Telegram コマンド

| コマンド | 内容 |
|---|---|
| 状況 | 保有と上位候補 |
| 候補 | エントリー候補ランキング |
| 持った GOLD | 指令どおり建てたとして記録 |
| 決済 GOLD | 両方閉じたとして記録 |
| 乗り換えた 銀 GOLD | 銀を決済してGOLDを建てたとして記録 |
| 反転した 銀 | 同じ銘柄で売り買いを逆に建て直したとして記録 |
| 残高 150 120 | PopDEX / Variational の残高 |
| レバ 3 | レバ上限（銘柄ごとの上限でさらに抑える） |
| 最大 2 | 同時保有数（証拠金は空き分で割り当て） |
| 範囲 広い / 主要 | 全銘柄 / 主要5銘柄（GOLD 銀 BTC ETH QQQ） |
| モード 常時 / 厳選 | 常時保有 / FR差が大きい時だけ |
| 設定 | 設定一覧。`設定 minDiff 0.03` で個別変更 |

## 主な設定（`設定 項目 値` で変更）

| 項目 | 初期値 | 意味 |
|---|---|---|
| holdMode | 1 | 1 = 常時保有 / 0 = 厳選 |
| holdDays | 30 | 常時保有: この日数持つ前提で順位付け |
| holdFloor | -0.005 | 常時保有: 建ててよい見込み受取差 %/日 の下限 |
| exitFloor | -0.01 | 常時保有: これを下回ると「悪化」 |
| minHoldHours | 24 | 常時保有: 建ててから乗り換え提案しない時間 |
| switchMinGain | 0.02 | 常時保有: 乗り換えに必要な受取差の改善 %/日 |
| exitHours | 24 | 悪化がこの時間続いたら乗り換え（または撤退） |
| switchDays | 3 | 乗り換えコストの回収日数の上限 |
| minDiff | 0.02 | 厳選: 受取差 %/日 の下限 |
| maxDays | 7 | 厳選: コスト回収日数の上限 |
| emaHours | 6 | FR差の平均化の時間幅 |
| minVol | 200000 | 全銘柄モードの24h出来高下限 $ |
| maxSpreadBps | 15 | 全銘柄モードのスプレッド上限 |
| takerBps | 3.2 | PopDEXの手数料（bps）。Variationalは0 |
| reportHour | 21 | 日報の時刻（日本時間） |
| altMaxLev | 3 | 主要5銘柄以外の暗号資産のレバ上限 |
| rwaMaxLev | 3 | 主要5銘柄以外の株・商品のレバ上限 |

## 注意

- 株・指数は米国の取引時間外、金属は日次休場と週末にはエントリーしない。アジア市場の銘柄（Samsung、日経など）は対象外
- 清算距離は「残高全部が証拠金・維持率0.5%」のざっくり推定
- 公開リポジトリで60日間アクティビティがないと、GitHub がスケジュール実行を止めることがある。止まったら Actions タブから再有効化する
- 指令は試算にもとづく目安で、利益を保証するものではない
